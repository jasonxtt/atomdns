# mosdns 分流顺序表（10.0.0.3）

## 说明

本文基于 `10.0.0.3` 当前运行配置整理，主要依据：

- `/cus/mosdns/config_custom.yaml`
- `/cus/mosdns/sub_config/rule_set.yaml`
- `/cus/mosdns/sub_config/process_v4.yaml`
- `/cus/mosdns/sub_config/process_v6.yaml`
- `/cus/mosdns/sub_config/process_ot.yaml`
- `/cus/mosdns/sub_config/special_groups.yaml`

这套配置不是“命中第一个域名集就立刻停”。

- 很多规则会先一起打上 `fast_mark`
- 后续再由 `sequence_ipv4` / `sequence_ipv6` / `sequence_other` 决定最终走向
- 只有少数规则是早停型，例如 `重定向`、`黑名单`、`DDNS`、`专属分流组`

## 一、A / AAAA 主分流优先级

适用于绝大多数常见域名解析请求。

| 顺位 | 规则/UI名称 | 运行标签/mark | 实际结果 |
| --- | --- | --- | --- |
| 1 | 重定向 | 直接走 `$rewrite` | 最早执行，命中后直接结束，不再看后面任何名单 |
| 2 | 黑名单 | `fast_mark 1` | 直接拦截 |
| 3 | 广告屏蔽 | `fast_mark 5` | 直接拦截 |
| 4 | DDNS 域名 | `fast_mark 6` | 直接走国内上游 `$domestic`，然后结束 |
| 5 | 专属分流组 | `mark 50-59` | 进入对应 `sequence_special_50~59`，走绑定上游并结束 |
| 6 | `!CN fakeip filter` | `!CN fakeip filter / fast_mark 9` | 直接走国外 realip 路径并结束 |
| 7 | `CN fakeip filter` | `CN fakeip filter / fast_mark 10` | 仅 CN FakeIP 开启时检查；直接走国内 realip 路径并结束 |
| 8 | 灰名单 | `灰名单 / fast_mark 7` | 走代理（FakeIP）并结束 |
| 9 | 白名单 | `白名单 / fast_mark 8` | 走国内并结束 |
| 10 | 代理域名 | `代理域名 / fast_mark 15` | 走代理并结束 |
| 11 | 直连域名 | `直连域名 / fast_mark 13` | 走国内并结束 |
| 12 | 非中国域名 | `非中国域名 / fast_mark 14` | 走代理并结束 |
| 13 | 中国域名 | `中国域名 / fast_mark 16` | 走国内并结束 |
| 14 | 记忆代理 | `记忆代理 / fast_mark 12` | 以上都没命中时，按学习结果走代理 |
| 15 | 记忆直连 | `记忆直连 / fast_mark 11` | 以上都没命中时，按学习结果走直连 |
| 16 | 列表外域名 | 无 | 靠上游返回 IP 再判断国内/国外 |

## 二、手动可维护规则的实际强弱

这是更接近 WebUI 使用习惯的一张表。

| 层级 | 规则 | 说明 |
| --- | --- | --- |
| 最高 | 重定向 | 命中后直接改写并结束 |
| 很高 | 黑名单 | 直接拦截 |
| 很高 | 广告屏蔽 | 直接拦截 |
| 很高 | DDNS 域名 | 直接国内解析并结束 |
| 很高 | 专属分流组 | 直接走绑定上游，优先于普通白/灰/订阅 |
| 高 | !CN fakeip filter / CN fakeip filter | 直接国外 / 国内 realip |
| 中高 | 灰名单 | 走代理，高于白名单 |
| 中 | 白名单 | 走国内 |
| 中 | 代理域名（自定义订阅） | 高于直连域名 |
| 中 | 直连域名（自定义订阅） | 高于基础规则 |
| 中低 | 非中国域名（基础规则） | 高于中国域名 |
| 中低 | 中国域名（基础规则） | 基础规则里最低 |
| 低 | 记忆代理 / 记忆直连 | 只在前面的名单都没命中时生效 |
| 最低 | 列表外域名 | 靠探测 IP 再分流 |

## 三、订阅规则和 UI 类型对应关系

| UI显示/类型 | 分组 | 插件Tag | 运行标签（schema 5 起） | 旧运行标签 | fast_mark | 归类 |
| --- | --- | --- | --- | --- | --- | --- |
| 代理域名 | 自定义订阅 | `cusnocn` | 代理域名 | 订阅代理补充 | 15 | 代理 |
| 直连域名 | 自定义订阅 | `cuscn` | 直连域名 | 订阅直连补充 | 13 | 直连 |
| 非中国域名 | 基础规则 | `geosite_no_cn` | 非中国域名 | 订阅代理 | 14 | 代理 |
| 中国域名 | 基础规则 | `geosite_cn` | 中国域名 | 订阅直连 | 16 | 直连 |
| 中国 IP | 基础规则 | `geoip_cn` | 无单独 domain tag | 无 | 无 | 主要用于列表外 IP 判断，不属于域名规则主标签 |

说明：

- 分流规则 › 在线订阅分两组：自定义订阅（直连域名、代理域名，可增删）和基础规则（中国域名、非中国域名、中国 IP，可关闭、可改地址，界面不允许删到零）
- 旧版本的运行标签带“订阅”字样，旧日志保留旧名称，程序两套名字都认
- 你在 WebUI 里新增订阅规则只能选直连域名或代理域名，保存后会真实参与分流
- `中国 IP` 也会生效，但它主要参与“上游返回 IP 后再判断国内/国外”的流程，不像前面几种那样直接显示成常规 `domain_set` 标签

## 四、常见冲突时谁赢

| 冲突情况 | 最终谁赢 |
| --- | --- |
| 重定向 和任何别的规则同时命中 | 重定向 |
| 黑名单 和 白名单/灰名单/订阅 同时命中 | 黑名单 |
| 专属分流组 和 白名单/灰名单/订阅 同时命中 | 专属分流组 |
| !CN fakeip filter 和 白名单/灰名单/订阅 同时命中 | !CN fakeip filter |
| 灰名单 和 白名单 同时命中 | 灰名单 |
| 代理域名 和 直连域名 同时命中 | 代理域名 |
| 白名单 和 非中国域名 同时命中 | 白名单 |
| 自定义订阅（直连域名/代理域名）和 基础规则 同时命中 | 自定义订阅 |
| 非中国域名 和 中国域名 同时命中 | 非中国域名 |

## 五、非 A / AAAA 请求顺序

非 `A`、`AAAA` 请求走的是 `sequence_other`，顺序明显更简单。

| 顺位 | 规则 | 实际结果 |
| --- | --- | --- |
| 1 | 重定向 | 直接结束 |
| 2 | 黑名单 | 直接拦截 |
| 3 | 广告屏蔽 | 直接拦截 |
| 4 | DDNS 域名 | 直接国内上游 |
| 5 | 专属分流组 | 直接走专属上游 |
| 6 | 中国域名 | 走国内上游 |
| 7 | 其他所有 | 走国外上游 |

这意味着在非 `A/AAAA` 请求里，下面这些规则并不直接决定最终方向：

- 白名单
- 灰名单
- 直连域名
- 代理域名
- 非中国域名
- `CN fakeip filter`
- `!CN fakeip filter`

## 六、为什么日志里会同时出现多个标签

因为当前 `domain_mapper` 允许同一域名同时命中多个规则，日志里的 `命中标签` 是拼接结果，不代表“排在前面的那个一定最终生效”。

当前拼接顺序大致是：

1. 黑名单
2. 记忆无V4
3. 记忆无V6
4. 广告屏蔽
5. DDNS域名
6. 灰名单
7. 白名单
8. !CN fakeip filter
9. CN fakeip filter
10. 记忆直连
11. 记忆代理
12. 直连域名（旧：订阅直连补充）
13. 非中国域名（旧：订阅代理）
14. 代理域名（旧：订阅代理补充）
15. 中国域名（旧：订阅直连）

所以像：

- `记忆代理|中国域名`
- `白名单|非中国域名`

都不稀奇，真正要看谁最终生效，还得结合：

- `final_sequence`
- `final_upstream`
- `effective_tag`

## 七、最简短结论

如果只想记住最核心的顺序，可以记成：

1. 重定向
2. 黑名单 / 广告 / DDNS
3. 专属分流组
4. `!CN fakeip filter` / `CN fakeip filter`
5. 灰名单
6. 白名单
7. 代理域名
8. 直连域名
9. 非中国域名
10. 中国域名
11. 记忆代理 / 记忆直连
12. 列表外域名
